# 编辑操作约定（0.5.0）

点击文字稿编辑文字，点击谱面编辑音乐，不再使用 F6 切换。文字、谱面、歌词和排版共用文档及撤销历史。自动分小节和自动换行随本次操作回写，不额外占一次撤销。

## 光标与输入

| 位置或操作 | 行为 |
| --- | --- |
| 点击中间音符／歌词，或用方向键导航到它 | 默认修改已有内容 |
| 选择末尾第一个虚线空格 | 默认连续追加 |
| Insert／工具栏“插入” | 直接输入在选中内容之后插入；后面的音符或歌词顺延 |
| 左右键 | 在当前声部的音符，或当前段的歌词之间前后导航；多选时先收拢到端点 |
| 上下键 | 按谱面位置在音符、各段歌词和标题等文字之间导航 |
| Ctrl+上下 | 切换声部 |
| End | 到当前声部的音符末尾，或当前歌词行的末尾空格 |
| Alt+上下（音符） | 改音高 |
| Esc | 先取消输入法组词／拖动预览，再返回谱面命令状态 |

谱面命令 B/Z/D/P 编辑题目、署名、调号、拍号，Q 新增独立声部，C 新增当前声部的一段歌词并从曲首填词。文字区中的字母保持普通文字输入。选中歌词后可直接用中文输入法填写；预编辑文字只用于预览，提交后才修改音乐。

中文逐字填入主音符词位，标点附于前一个字，`@` 空一个词位，`你~好` 为一个词位。休止符、倚音和延音后续音自动跳过，普通连奏线内的每个音符仍可分别填词。多段使用重复的 C1/C2，数字仍表示声部；界面显示段次。歌词超出一个 Q 行时继续分配给同声部后续曲行，文字稿随谱面重新拆为对应的 Q/C 行。

## 范围选择与搬移

| 手势 | 行为 |
| --- | --- |
| 从未选中的音符／歌词上按住拖动 | 连续划选到落点；可跨谱行 |
| Shift+点击 | 选择锚点和落点之间的全部音符／词位 |
| Ctrl+点击 | 增加或取消一个选择；Ctrl+Shift+点击扩展现有选择 |
| 点击小节内没有音符的空白区域 | 选择整小节的全部声部 |
| 从未选中的小节空白开始拖动 | 连选多个小节 |
| 小节 Ctrl+点击／Shift+点击 | 非连续多选／连续范围选择 |
| 按住已经选中的音符、歌词或小节拖动 | 搬移内容，蓝色标记表示插入落点 |
| Ctrl+拖动已选内容 | 保留原内容，在落点复制插入 |

先选择，再从选区内开始拖动；从未选中内容开始拖动用于划选。落在自己的选区内不重复插入。Esc 取消拖动。音乐内容拖动与标题、记号的图形位置调整使用不同的处理路径。

音符范围以同一声部为单位，歌词范围以同一声部、同一段为单位；需要跨声部一起操作时选择整小节。和弦可点选其中一个音，Shift 时间范围会包含端点时刻的整和弦。复制完整连音组保留其比例；不完整的连音组若不能安全粘贴，会保留原曲谱并提示完整选取。

## 复制、插入与覆盖

| 操作 | 行为 |
| --- | --- |
| Ctrl+C | 复制已选音符、歌词或一节／多节 |
| Ctrl+V，修改／覆盖模式 | 从目标起点按复制内容的时值覆盖；小节按整节替换 |
| Ctrl+V，插入模式，或 Ctrl+Shift+V | 在目标起点之前插入，后续内容顺延 |
| 多节复制后选择一个目标小节粘贴 | 从此小节开始依次覆盖相同数量的小节；超出曲尾时追加 |
| 多节复制后选择多个非连续目标小节覆盖 | 按目标小节顺序逐个替换，不影响中间未选中的小节；复制内容还有剩余时，从最后目标之后继续 |
| 整节复制后点击音符粘贴 | 以该音符所属小节为目标 |
| Delete 删除多选音符／小节 | 音符在当前声部内顺延，小节在全曲顺延；被删除音符的歌词留在待分配区 |
| 歌词选区内输入或粘贴普通文字 | 替换所选词位，后续歌词顺延，音符不变 |

整节包括全部声部及其歌词和内核可复制的记号；非连续源小节只复制选中的小节，按原顺序组成片段。音符插入后原有歌词跟随原音符，搬移歌词不会改变音乐。每次粘贴或搬移整体提交，失败时原文档不变，Ctrl+Z/Y 整次撤销／重做。

## 图形调整与排版

标题、副标题、署名、调拍号、注释和表达记号均可选中后拖动，靠近其他元素的边缘或中心时吸附并显示辅助线。Alt 拖动取消吸附。圆柄旋转、方柄等比缩放，右侧属性可输入角度和缩放百分比；旋转接近 15° 倍数时吸附，Alt 取消。

方向键用于导航；选中图形后 Alt+方向键移动 1 px，Ctrl+Alt+方向键精调 0.2 px，Shift+Alt+方向键移动 10 px。音符和歌词由音乐词位决定排版，不进行图形偏移、旋转或缩放。

“排版 → 行与页 → 多段歌词显示编号”在行左侧绘制段次，不占用任何歌词词位。记号在所属音符的上下方采用紧凑的固定层，歌词为下方力度和渐变力度留空间。图形变换和排版设置保存在 `.jianpu`；MusicXML/MIDI 导出保留音乐信息，不承载本应用的全部简谱几何调整。

## 文字一致性与导出

正常的第二段歌词、跨小节长音、自动换行不会启用受保护状态。旧工程中因为这些情况而未提交的有效草稿，在打开时重新验证并恢复。实际包含当前语法无法表达的和弦或原生乐器定义等对象时，仍保留内核完整数据；可以继续谱面编辑，也可以从文字稿修改歌词和元数据，不能用不完整的正文覆盖原音乐。

导出前重新验证当前文字、未闭合结构和待分配歌词。整首仍容纳不下或删除音符后留下的歌词不会丢弃：可以填写到合适词位，或在属性面板明确“移除待分配歌词”，该操作可撤销。未完成草稿可以保存工程；批量搬移／粘贴前需完成当前未提交输入，避免覆盖草稿。

本轮 Linux Release/Debug 和输入法提交事件测试见 [验证记录](verification.md)。Windows 的真实输入法、拖动和部署仍需实机验收。
